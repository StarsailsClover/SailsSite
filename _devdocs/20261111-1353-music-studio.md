# Sails Music Studio

请求时间: 2026-11-11 13:53 HKT

## 目标

- 主站 `/music` 从静态播放列表升级为个人音乐创作作品页。
- 展示专辑、单曲、歌手资料、单曲封面、流派、发行信息与播放状态。
- 单曲支持标准 LRC 时间戳歌词，以及可选的中文翻译 LRC。
- 播放器支持逐行高亮、点击时间戳跳转，并继续复用全站悬浮播放器。
- 管理端支持上传音频、封面上传、维护专辑与单曲信息。

## 设计

- 延续夜雾黑绿、暖金与冷水的现有视觉语言。
- 沿用现有 React 18 + 原生 CSS，不引入 Astryx 或第二套组件系统。
- 专辑列表与详情采用 12 栏布局，移动端单栏，所有主要触控目标不小于 44px。
- 管理端增加“音乐”工作区，沿用合集管理的双栏结构与移动端双 pane。

## 数据

- `music_albums`: 名称、slug、歌手、歌手简介、简介、封面、流派、发行日期、状态、版本。
- `music_tracks`: 所属专辑、名称、歌手、封面、流派、音频、时长、曲序、原文 LRC、翻译 LRC、状态、版本。
- 公共 API 只返回已发布专辑与已发布单曲。
- 管理 API 需要现有 HttpOnly session、CSRF 和 API 版本头。
